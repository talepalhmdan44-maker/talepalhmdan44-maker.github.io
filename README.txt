FREE PUBLISHING OPTION: GITHUB PAGES
1. Create a free account at https://github.com
2. Create a new PUBLIC repository named: yourusername.github.io
3. Upload all five website files to the repository root.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and /(root), then Save.
7. After publishing, your site should appear at https://yourusername.github.io

Before publishing:
- Replace the contact placeholder in privacy.html with a real contact method.
- Confirm and adapt the privacy policy to any analytics, forms, cookies or other tools you add.
- Add researched products with original descriptions and accurate product information.
- Apply to the Amazon Associates program and wait for approval before using affiliate links or claiming Associate status.
- Replace generic retailer links with your own approved Special Links.
- Check Amazon's current country, tax, identity and payment requirements for your actual country of residence and bank.
- Do not use a false address, identity or bank details.
